# 美術聖經 v1.0｜蠟筆小鎮（暫名）
### Storybook Crayon World — 蠟筆故事書世界觀美術規範

---

## 0. 專案定位重述

這是一款**休閒跑圖收集遊戲**：小朋友放學／出門，搭公車前往五個地點（阿姨家、便利商店、學校、阿嬤家、公園），途中要**躲貓狗**、**撿點心與寶物**，最後**趕上公車回家**，家（臥室）是玩家的**基地 BaseHub**。

**上一版問題診斷**：直接套用 Poly Haven 寫實 PBR 模型、整體上粉色貼圖。這只是「把寫實的工廠塗成粉紅色」，材質邏輯（粗糙度、法線細節、真實比例）仍是寫實的，所以看起來像「粉紅色的瀝青馬路」而不是「遊樂場」。**可愛感不是色相問題，是形狀語言、比例、材質邏輯三者同時改變的結果**，必須從 Blockout 階段就用新規則重做，不是換貼圖。

**美術基準**：動物森友會（圓潤巨大化道具、無寫實陰影）、Tearaway（紙藝摺疊感、厚紙板倒角）、星之卡比（圓胖主體、超誇張比例、糖果色塊）。**地域融合**：台灣童年街景（透天厝、鐵窗花、機車、柑仔店、校門口、公車亭）。

## 1. 核心原則與禁忌

### 1.1 三大鐵律

1. **沒有一條邊是直的、沒有一個面是水平的**
   所有建築牆面、路緣、招牌都要有 1–3° 的隨機傾斜或微彎，故事書的「手繪感」來自這種不完美對稱。程序化生成時，每個建築 instance 要在傾斜角度上加 `Random.Range(-2.5f, 2.5f)` 的 noise，但同一棟建築四個角要**相互關聯地歪**（整體傾斜而非扭曲變形），不能歪到穿插破面。

2. **比例先決定，寫實參考後決定**
   先定角色與道具的比例關係（第 3 章），再去思考「這東西現實上長怎樣」。現實比例是最後 10% 的辨識度調味，不是基礎。

3. **材質只分三層，禁止使用寫實 PBR 工作流**
   見第 12 章。禁止 Metallic/Roughness 貼圖直接套用在任何建築/道具/角色上，禁止法線貼圖製造「真實磨損」效果（刮痕、污漬、鏽蝕紋理）。

### 1.2 禁忌清單（Do NOT）

| 禁止 | 原因 | 改用 |
|---|---|---|
| 把寫實模型整體換色（Poly Haven 式作法） | 形狀仍寫實，換色只會更假 | 重新 Blockout，圓胖化比例 |
| 真實磚紋/水泥紋/鐵鏽貼圖 | 立刻拉回寫實感 | 色塊分色 + 手繪筆觸 Albedo，無凹凸細節 |
| 高精度法線貼圖（毛孔感、刮痕、裂縫） | 遊樂園感的敵人 | 法線貼圖只用於「大塊面摺痕」如紙藝摺紙感，不用於表面瑕疵 |
| 寫實陰影/高強度 Specular 反射 | 讓物體看起來濕黏、工業 | 卡通漸層陰影 Toon Shader，無鏡面高光或極弱高光 |
| 90° 直角牆角、銳利邊緣 | 玩具感的反面 | 所有外露邊緣倒角（見 3.2） |
| 細長比例（如寫實電線杆、真實門框高寬比） | 讀起來像縮小版真實世界而非玩具世界 | 誇張矮胖化，見第 3 章比例表 |
| 全場景單一色調貼滿（一次性粉紅所有東西） | 本案發生的錯誤本身 | 五色色票系統分區塊配色，見第 2 章 |
| 真實車輛比例的公車/機車（寫實引擎蓋、後照鏡細節） | 太真實會突顯周圍卡通化的違和 | 全部矮胖圓潤化，見第 7 章 |
| 雜訊貼圖模擬自然材質（草地雜訊、樹皮紋理) | 寫實質感入侵 | 平面色塊 + 外輪廓暖色描邊 |

### 1.3 "一句話測試"

> 把任何一個新資產放進場景截圖，問：「如果把這個單獨剪下來，貼在繪本跨頁插畫上，違和嗎？」
> 如果答案是「會違和、看起來像從別的遊戲貼過來的」，就退回重做形狀語言，不要只調顏色。

## 2. 色票系統

### 2.1 主色票（五色糖果色，各地圖依場景挑 2–3 主色 + 1 點綴）

| 色名 | Hex | 用途 |
|---|---|---|
| 糖果粉 Candy Pink | `#FF9ECD` | 建築主牆、公車車身、花朵 |
| 薄荷綠 Mint | `#8FE3C8` | 草地、樹葉、鐵窗花、招牌底 |
| 奶油黃 Butter Yellow | `#FFE29A` | 道路、沙地、燈光、窗框 |
| 薰衣草紫 Lavender | `#C9B6F2` | 天空漸層上層、陰影色、屋頂 |
| 天藍 Sky Blue | `#9FD8F5` | 天空漸層下層、水窪、制服 |

### 2.2 輔助色票

| 色名 | Hex | 用途 |
|---|---|---|
| 暖深棕（輪廓線/描邊） Outline Brown | `#5B3A3A` | 所有外輪廓描邊、窗框陰刻線、招牌文字 |
| 深可可（陰影暗面） Shadow Mocha | `#8A6FA8`（即薰衣草色系降明度） | 卡通陰影色，絕不用純黑或純灰 |
| 奶白（亮面/雲） Cream White | `#FFF8EC` | 雲朵、窗玻璃反光、招牌底 |
| 焦糖橘（點綴/警示） Caramel Orange | `#FFB36B` | 公車站、警示錐、招牌强調字 |
| 草綠（加深薄荷，樹幹/地面陰影區) Moss | `#5FAE8C` | 樹叢暗面、草地陰影 |

**規則**：
- **輪廓線永遠用 `#5B3A3A`（暖棕），不用黑色** — 黑色輪廓會把畫面拉回「卡通貼紙感」而非「蠟筆繪本感」，暖棕讓線條像蠟筆描線。
- 陰影永遠疊加**薰衣草/可可色系**（Shadow Mocha `#8A6FA8`），絕不用灰階或純黑陰影 — 這是本案最常見的「假粉紅」病灶：陰影用了寫實灰階，導致整體看起來髒。
- 每張地圖最多使用 **3 個主色 + 2 個輔助色**，禁止五色一次全上（否則變成大雜燴），見第 10 章各地圖配色。

## 3. 形狀語言與比例規則

### 3.1 全域造型語言

- **圓胖厚實（Chubby & Chunky）**：所有實體以「膠囊體 + 大倒角立方體」為基礎幾何，禁止使用寫實的細長柱體、薄板結構。
- **誇張比例（Exaggerated Proportion）**：寬 > 高 > 深，物體看起來像被「坐扁的麻糬」，但角色例外（角色頭大身小，見 3.3）。
- **歪斜剪影（Wonky Silhouette）**：見 1.1。
- **厚度優先**：任何「應該很薄」的東西（招牌、鐵窗花、公車玻璃框）在這個世界裡都要有**至少 8–12cm 的實際厚度**，像厚紙板剪出來的。

### 3.2 具體數字規範（給程序化建模用）

| 項目 | 規則 |
|---|---|
| **邊緣倒角半徑** | 建築/道具外露邊緣：半徑 = 物體最短邊的 **8–15%**，最小值 6cm，最大值 25cm。小道具（寶物、點心）：半徑 = 最短邊的 **20–30%**（更圓潤） |
| **牆面傾斜** | 每棟建築整體向內或向外傾斜 **1.5°–4°**（Random per-instance），同一棟四面牆用同一個傾斜 seed 做關聯變形，避免穿模 |
| **門比例（寬:高)** | 1 : 1.1 〜 1 : 1.3（接近正方形，禁止寫實門的 1:2.2 瘦長比例） |
| **窗比例** | 窗框寬:高 = 1:1 〜 1:1.2，且窗面積占牆面 **35–50%**（超大窗，比寫實建築多 2–3 倍） |
| **角色 : 門高度比** | 角色站立身高 = 門高的 **55–65%**（角色矮，門誇張地大，製造「小朋友的世界」感）。例：角色身高 1.0m（遊戲內單位），門高 1.6–1.8m |
| **角色 : 公車比** | 角色身高 = 公車車身高度的 **35–45%**（公車矮胖巨大化，但不是寫實大巴高度） |
| **角色頭身比** | 1.5–1.8 頭身（大頭小身，Q版），頭寬 = 肩寬的 **80–100%** |
| **屋頂坡度** | 固定在 **25–35°**（比寫實斜屋頂更低矮渾厚，避免尖銳三角形輪廓），屋頂邊緣出挑 20–30cm 並做大倒角 |
| **柱體最小直徑** | 任何柱狀物（電線桿、欄杆、招牌支架）最小直徑 = 高度的 **6%**（禁止寫實的細長比例，如現實電線桿直徑/高度約 1–2%） |
| **招牌厚度** | 最小 10cm，邊緣全倒圓 |
| **路面寬度誇張比** | 道路寬度以「夠兩個角色並肩走」為基準誇張放大 1.3–1.5 倍於寫實比例 |

### 3.3 角色造型快速檢查

- 頭大身小，四肢圓胖如香腸，手掌/鞋子誇張放大（增加可愛的「笨拙感」）。
- 衣服邊緣全部用布料厚緣處理（像厚紙剪影疊加），不用薄片貼圖模擬衣料。

## 4. 建築語言（台灣童年融合）

### 4.1 透天厝（主要住宅建築)

- **主體**：3–4 層樓簡化為 **2 層視覺高度**（樓層數用窗戶排數暗示即可，不用真實樓層高度堆疊，避免建築過高破壞構圖）。
- **鐵窗花**：這是台味精華，必須保留但**圖像化**——把鐵窗花幾何簡化成 2–3 種重複的「糖果幾何圖騰」（愛心、花朵、波浪線），用薄荷綠或焦糖橘上色，**鐵窗本身要有厚度**（8–10cm），避免變成貼圖花紋貼在平面上。
- **鐵捲門**：簡化成大色塊 + 橫向溝紋（3–5 條淺溝，溝深不超過 3cm，用純色分色而非凹凸貼圖表現溝紋），捲門收起時的捲軸箱做成圓胖膠囊體。
- **遮雨棚（騎樓棚)**：帆布感，用微彎曲面 + 鋸齒下緣（像蠟筆畫的波浪剪裁），顏色用奶油黃或天藍加白色條紋。
- **招牌**：所有招牌做成**厚招牌**（10–15cm 厚），邊角全倒圓，文字用暖棕色粗體手寫感字型，招牌要略微傾斜懸掛（像真的用兩條鐵鍊吊著，增加生活感）。
- **外牆磁磚**：不用真實磁磚貼圖，改用**大色塊分割 + 暖棕勾縫線**（勾縫線寬 2–3cm，用模型幾何凹線或純色貼圖線條，不用法線貼圖）。

### 4.2 鐵窗花程序化建模建議

用一個「花紋模組」Prefab（3–4 款），沿窗框做陣列複製，模組本身是擠出（Extrude）的 2D 圖騰 + 厚度，材質固定用單一輪廓色 + 單一面色，不做漸層。

### 4.3 柑仔店／雜貨店

- 低矮圓胖的店面 + 外擺零食架（零食用誇張放大的糖果/餅乾模型，見第 5 章道具）。
- 店門口放一台簡化的紅色大冰箱飲料櫃（方塊倒角 + 圓把手），這是最強的台灣懷舊符號之一。
- 店面招牌用焦糖橘手寫字樣，可放「雜貨」「柑仔店」字樣簡化圖形（非真實文字渲染，用美術手繪字型貼圖）。

### 4.4 學校大門

- 校門做成**巨大圓拱 + 兩側矮胖門柱**，門柱頂端放簡化小地球/鐘的裝飾球體。
- 圍牆矮化（視覺上到角色胸口高度即可，不做寫實圍牆高度），圍牆上重複貼合薄荷綠瓷磚色塊紋。
- 警衛室做成一個圓胖的小木屋造型，窗戶超大。

### 4.5 公車亭

- 站體用三片彎弧頂棚（像摺紙傘），顏色天藍+奶白條紋。
- 長椅做矮胖圓角長方體，椅腳加粗加短。
- 路線牌做成大圓牌懸掛，不用寫實金屬桿支撐，用膠囊體支柱。

## 5. 道具（點心寶物、環境小物）

- **食物道具誇張放大 1.5–2 倍於合理比例**（棒棒糖、麵包、飯團），形狀圓潤飽滿，高光用 1–2 筆簡化白色色塊而非真實高光貼圖。
- **寶物（星星、貝殼、彈珠）**：全部用簡單幾何（球體/星形擠出體）+ 高倒角，表面加 1 條暖色輪廓線，閒置時可做簡單上下浮動 + 自轉動畫，強化「玩具感」。
- **路邊小物**：消防栓、垃圾桶、路燈、郵筒 → 全部矮胖化，路燈燈罩做成圓滾滾的糖果形。
- **原則**：任何道具優先用「可以被小孩抱著的尺寸感」去設計形狀，即使它在現實中是巨大物體（如郵筒），在這個世界裡都要顯得「抱得動」。

## 6. 自然元素（樹、草、花、雲）

| 元素 | 規則 |
|---|---|
| **樹** | 樹冠用 2–3 顆重疊的圓胖球體/雲朵狀幾何堆疊（不用寫實枝葉散射系統），樹幹短胖且略彎，樹皮不用紋理貼圖，改用深淺雙色塊（主色+加深 15% 明度做暗面) |
| **草地** | 不用真實草葉 Billboard/Shader 草地系統，改用**地面色塊 + 邊緣波浪剪影**（像蠟筆畫的草地輪廓線），局部點綴簡化叢狀草堆 Mesh（3–5 片扇形葉面，無交叉穿插細節) |
| **花** | 5–6 瓣簡化圓形花瓣，花心用對比色點，花可做群組 Prefab 隨機散佈，不做花瓣透光材質 |
| **雲** | 奶白色，3–4 顆球體堆疊的經典「棉花糖雲」，邊緣可加極淺的薰衣草陰影面（底部），雲朵可飄移動畫增加場景活性 |
| **天空** | 雙色漸層 Shader（上方薰衣草 `#C9B6F2` → 下方天藍 `#9FD8F5`），禁止使用寫實 Skybox 貼圖/HDRI |

## 7. 載具

### 7.1 公車
- 車身矮胖圓潤（長寬比降低，接近寫實公車的 70%），四個角全倒大圓角。
- 車窗連成一長條超大弧形窗（可愛校車既視感），窗框厚 10cm。
- 輪胎縮小且內縮進輪拱（像玩具車輪胎卡進車身，不露出寫實懸吊結構）。
- 車頭燈/尾燈做成圓形凸起色塊，無寫實燈殼透明材質。
- 車身主色用糖果粉或天藍，配白色腰線。

### 7.2 機車
- 台灣街景必備符號。整體矮胖化，油箱放大成圓滾滾造型，後照鏡加大加圓（像米老鼠耳朵），輪胎加粗。
- 不做寫實引擎細節/排氣管金屬質感，用單一色塊 + 暖棕描邊線表示機械分件。

### 7.3 腳踏車
- 車架用膠囊體彎管，車輪加粗，籃子（如有）放大加圓潤。

## 8. 寵物（貓狗，躲避敵人設計）

**設計目標**：牠們是「要躲開的威脅」但視覺上不能太可怕（休閒遊戲），用**圓胖＋大眼睛＋誇張動作**傳達「警戒/調皮」而非「兇惡」。

| 項目 | 規則 |
|---|---|
| 身體比例 | 頭身比 1:1.2，身體渾圓如豆子，四肢短胖 |
| 表情 | 用簡化的大圓眼 + 單一眉毛線條表達警戒狀態，禁止寫實齜牙/利爪細節 |
| 貓 | 尾巴誇張加長加粗並上翹，耳朵做成大三角形圓角，可用亮眼色（薰衣草/焦糖橘）作為毛色點綴而非全身粉色化 |
| 狗 | 耳朵下垂圓潤或立耳圓潤二選一依品種，身形比貓更矮胖，尾巴短粗搖擺 |
| 警戒動畫 | 用「發現玩家時身體彈跳一下 + 耳朵立起」取代寫實撲咬動畫，降低恐怖感同時保留躲避遊戲的緊張節奏 |
| 配色 | 貓狗保留「花色辨識度」（如橘貓用焦糖橘斑塊、黑白貓用暖棕斑塊），不要全部漂白成粉紅色——**這正是本案被罵的核心錯誤**：寵物/建築不應該被「一色粉紅洗版」，而是用五色票系統做材質分區 |

## 9. 臥室基地（BaseHub）

- **核心情緒**：安全、溫暖、個人化收藏展示空間。
- **床**：加大加厚床墊，床頭板做圓拱大倒角造型，棉被用簡化格紋色塊（2 色交錯，非寫實布紋貼圖）。
- **窗**：沿用超大窗規則，窗外可見目前天色（呼應地圖日夜/天氣系統），窗框用奶油黃。
- **收藏展示牆**：預留牆面供玩家擺放/展示收集到的寶物（開放式層架，矮胖圓角層板），這是獎勵回饋的視覺焦點，照明比房間其他地方略亮、可加極輕微的暖色高光點（不是寫實打光，是卡通強調色塊）。
- **牆色**：建議用薰衣草或奶油黃為主牆色，避免用糖果粉（避免跟外部地圖的粉色產生疲勞感，基地要有「不同但同源」的區隔感）。
- **地板**：木地板簡化為暖棕+奶油黃交錯色塊拼貼，無木紋貼圖細節。
- **互動物件**：書桌、玩具箱、衣汃，全部套用圓胖厚實規則，書桌上可放置目前劇情道具作為敘事暗示。

## 10. 五張地圖佈局、地標、動線、天光

**通用動線原則**：每張地圖是「公車站（起點/終點）→ 中段躲避關卡 →地標目的地」的線性或環狀路線，寶物散佈在路線兩側的「安全支線」誘導玩家小偏移但不會真正走丟，貓狗巡邏區集中在中段 60% 路段。

### 10.1 阿姨家（Aunt's House）
- **配色**：主色糖果粉 + 奶油黃，點綴薰衣草。
- **佈局**：巷弄型關卡，兩側透天厝夾出一條小巷，終點是阿姨家（鐵窗花最密集的一棟，門口有盆栽裝飾），強調「鄰里感」。
- **地標**：巷口柑仔店（可選支線撿零食）、曬衣竿陣（晾曬的衣物可做輕微飄動裝飾，不擋路）。
- **動線**：S 形巷弄，2 處巷口可躲貓（利用轉角視線死角設計躲避玩法）。
- **天光**：午後斜陽，天空薰衣草→奶油黃漸層，長而柔和的暖色調陰影（用 Shadow Mocha 色），營造放學後巷弄的溫暖慵懶感。

### 10.2 便利商店（Convenience Store）
- **配色**：天藍 + 奶油黃，點綴焦糖橘（招牌色）。
- **佈局**：開放小廣場型，便利商店主建築居中偏後，前方停車格/機車停放區作為躲避機車/巡邏狗的開放戰場。
- **地標**：巨大化的店招牌燈箱（夜間會發光，呼應第 12 章 Emission 規則）、店前霜淇淋機模型（寶物彩蛋位置）。
- **動線**：放射狀，玩家可從三個入口接近商店，增加路線選擇感；貓狗繞商店週邊巡邏一圈。
- **天光**：接近黃昏，天藍偏暗一階，招牌與窗內燈光成為視覺焦點（Emission 色用焦糖橘/奶油黃）。

### 10.3 學校（School）
- **配色**：薄荷綠 + 奶油黃，點綴天藍（制服色呼應）。
- **佈局**：校門為起點，中庭操場為核心躲避區（開闊視野訓練躲狗走位），教學樓在最深處作終點地標。
- **地標**：巨大校門拱門、操場單槓/滑梯（可當視覺遮蔽物設計躲避動線）、升旗台。
- **動線**：中心對稱佈局，操場周圈走廊式路線，貓狗巡邏繞操場邊緣，中央保持安全區（呼應真實下課躲避經驗）。
- **天光**：明亮正午，天藍為主調天空，陰影短而乾淨（Shadow Mocha 淡一階），整體最高飽和度、最有活力的一張地圖。

### 10.4 阿嬤家（Grandma's House）
- **配色**：薰衣草 + 奶油黃，點綴草綠（Moss，呼應庭院感）。
- **佈局**：郊區小庭院型，比阿姨家更寬鬆、綠意更多，老式透天厝＋小院子＋曬穀場感的開放空地。
- **地標**：院子大樹（最大樹冠 Prefab，可做乘涼/視覺中心）、老式竹椅/藤椅群、神明桌窗景（遠景剪影暗示，不做細節神像）。
- **動線**：環繞大樹的環狀路線，貓（阿嬤家的貓)活動範圍以樹為中心，給玩家明確的「繞樹躲貓」直覺玩法。
- **天光**：最溫暖的一張，近日落，薰衣草天空比例最高、搭配奶油黃地面反光，營造「最想念阿嬤家」的懷舊暖調。

### 10.5 公園（Park）
- **配色**：薄荷綠 + 天藍，點綴糖果粉（遊樂設施點綴色）。
- **佈局**：最大最開放的地圖，核心是中央遊樂區（滑梯/鞦韆/翹翹板大型化道具），四周環狀步道+草坡。
- **地標**：巨大滑梯（可作為地圖最高視覺地標）、噴水池（簡化水面 Shader，無寫實水反射，用淡藍半透明色塊+白色波紋線)、花圃（第 6 章花朵群組 Prefab 密集擺放處）。
- **動線**：環狀步道外圈為主要巡邏/躲避路線，遊樂設施區為安全休息區（寶物密集區），鼓勵玩家在外圈躲避後進入中心補給。
- **天光**：清爽上午，天藍飽和度最高，雲朵（第 6 章棉花糖雲)數量最多且有飄移動畫，整體節奏最輕快。

## 11. UI

- **字型**：圓潤手寫/哥德圓體風格字型，粗邊框，避免細字重的寫實字型。
- **按鈕**：全部用「膠囊體 + 大倒角」造型呼應世界觀，按下時做 Q 彈 Squash & Stretch 動畫（非寫實按壓位移）。
- **邊框**：UI 面板邊框用暖棕色粗邊線 + 奶白底，呼應繪本頁框感，可加細微鋸齒/波浪邊緣強化「紙藝剪裁」感。
- **圖示（Icon）**：寶物/道具圖示直接沿用 3D 模型的簡化剪影，保持色票一致，不額外設計扁平化風格圖示系統（避免兩套視覺語言打架）。
- **色彩**：UI 主色建議用焦糖橘（CTA 按鈕）+ 奶油黃（面板底），避免大量使用糖果粉以免與場景粉色衝突導致 UI 與場景分不清層次。
- **動效**：所有 UI 轉場用彈跳/Q 彈曲線（Ease Out Elastic / Overshoot），不用線性或寫實緩動曲線。

## 12. 材質與著色器規則

### 12.1 三層材質結構（取代寫實 PBR）

1. **Albedo 色塊層**：手繪分色，無細節紋理，每個物體分 2–4 個色塊區域（主色/暗面/點綴/描邊）。
2. **Toon Shading 層**：使用 Cel-shading / Toon Lit Shader，光照分為 **2 階**（亮面/暗面），暗面統一疊加薰衣草/可可色系（`#8A6FA8` 附近色），**不使用寫實 PBR 的 Roughness/Metallic 貼圖**，Smoothness 固定給低值（0.1–0.2），避免鏡面反光。
3. **輪廓線層**：Outline Shader（反向法線擠出法或後處理邊緣偵測皆可），線寬固定、顏色固定用暖棕 `#5B3A3A`，**全場景統一線寬比例**（約螢幕空間 2–3px 等效），不隨距離大幅縮放到消失。

### 12.2 具體 Shader 參數建議（Unity URP 為例）

- 使用 Toon Shader（可用 URP Toon Shader 範本或自寫 Shader Graph）：
  - Light Band 數：2（亮/暗），不做漸層平滑過渡，邊界可加極輕微抗鋸齒羽化（1–2px）即可，保持「色塊感」。
  - Specular：關閉或極弱（高光僅用於眼睛/金屬件等極少數「故事書強調點」，如寶物閃光）。
  - Rim Light：可加極弱暖色 Rim Light 模擬蠟筆繪本的邊緣光暈感，強度控制在不搶走輪廓線的程度。
- **禁止**：Normal Map 用於表面瑕疵、Metallic Workflow、PBR 材質球直接套用、SSR/寫實反射探針。
- **Emission**：僅用於招牌燈箱、路燈、公車車燈等「劇情需要發光」的物件，Emission 色需取自色票（焦糖橘/奶油黃），不用純白發光。
- **貼圖解析度原則**：Albedo 貼圖以「手繪色塊」為主，解析度可低（256–512px 足夠），因為沒有細節紋理需要高解析度支撐，有利於程序化場景的效能。

### 12.3 程序化建模 pipeline 建議

1. Blockout 階段直接套用第 3 章比例規則（倒角/傾斜/門窗比）跑一版灰模，先確認剪影可愛度，再上色。
2. 色票以 ScriptableObject 或 Material Palette Asset 集中管理，每張地圖引用對應的 3+2 色子集（見第 10 章），避免美術人員各自調色導致色彩漂移。
3. 鐵窗花、雲朵、花叢、樹冠等重複元素做成 Prefab 模組 + 程序化陣列/散佈腳本（可用 Unity 的 `GameObjectBuilder`/Probuilder 或自寫 Editor Tool），確保全場景造型語言一致。

## 13. 驗收清單（Art Review Checklist）

在任何新資產/場景提交前，逐項打勾：

**形狀語言**
- [ ] 所有外露邊緣已套用倒角（半徑符合 3.2 規則）

- [ ] 門窗比例符合第 3 章規則（窗佔牆面 35–50%，門寬高比 1:1.1–1.3）
- [ ] 角色站在門/公車旁時，比例符合角色:門、角色:車 的高度比規則

**色彩**
- [ ] 本場景只用了 3 主色 + 2 輔助色，沒有單一粉色洗版全場
- [ ] 陰影使用薰衣草/可可色系疊加，沒有出現灰階或純黑陰影
- [ ] 輪廓線統一為暖棕 `#5B3A3A`，沒有黑色描邊

**材質**
- [ ] 沒有任何物件使用寫實 PBR 貼圖（Metallic/Roughness/高精度 Normal Map）
- [ ] Toon Shader 光照分階清晰（2 階），Smoothness 低，無寫實鏡面高光
- [ ] 沒有使用寫實紋理（磚紋/水泥紋/木紋/布紋貼圖），全部為手繪色塊分色

**台味融合**
- [ ] 鐵窗花/鐵捲門/招牌等台灣元素已圖像化簡化，保留厚度與圓角，而非直接貼真實紋理
- [ ] 建築/寵物保留花色/分區配色辨識度，而非整體單色覆蓋

**地圖與動線**
- [ ] 該地圖的天光/色調符合第 10 章指定時段情緒
- [ ] 貓狗巡邏區域與寶物支線路線不衝突，核心動線清晰可讀
- [ ] 地標在剪影層級（灰階縮圖測試）仍可一眼辨認

**最終測試**
- [ ] 通過「一句話測試」（1.3）：單獨截圖放進繪本跨頁不會違和
- [ ] 截圖轉灰階後，仍可透過形狀（非顏色）分辨出建築/角色/寵物/道具類別

## 15. 資產計畫

### 15.1 全部捨棄
- **所有 Poly Haven 寫實模型與貼圖**（asphalt/brick/carpet/concrete/container/corrugated/deskwood/dirt/grass/metal/plaster/roof/tiles/woodfloor 等 Tex，及寫實家具 FBX）。

### 15.2 Unity 程序化建模（自建圓角模組套件，主力）
用一個 `SoftKit` 產生器：圓角盒（可調倒角半徑、頂點擾動做歪歪剪影、上窄下寬 2–4° 傾斜）、圓柱、膠囊、拱形、波浪簷口，全部頂點色＋Toon shader 蠟筆紋理，不用照片貼圖。
- **建築**：透天厝模組（1–3 樓、圓窗/拱窗、超大門、鐵捲門、遮雨棚、陽台、花形鐵窗花＝2D 輪廓擠出）、便利商店膠囊屋、學校教室棟＋拱門、阿嬤土角厝＋弧瓦屋頂（瓦片＝重複半圓柱）、公車亭。
- **室內**：牆地板殼、圓胖沙發、冰箱、電視櫃、課桌椅、貨架、櫃台、床、衣櫃、書架、撲滿。
- **自然**：棒棒糖樹／雲朵樹冠（球體群）、圓灌木、花叢（billboard 或小球）、草地用 shader 筆觸而非草模型、柿子樹、榕樹（加鬚根圓柱）。
- **街道**：路面、人行道、斑馬線、路燈、郵筒、垃圾桶、交通錐、圍籬、長椅。
- **公車**：矮胖車體＋大圓眼車燈（程序化，配合現有 Bus.cs）。
- **機車／腳踏車**：簡化圓角組件拼裝。
- 優點：風格 100% 統一、可隨機變體、檔案小（WebGL 友善）、無授權問題。
