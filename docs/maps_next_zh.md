總覽圖：`/workspace/maps_proposal.jpg`；各張草圖：`docs/map_lib.jpg`、`map_farm.jpg`、`map_school.jpg`、`map_night.jpg`（草圖，不是正式美術）。

## 一、現在的阿姨家是怎麼做的

| 部分 | 在哪裡 | 新地圖能不能直接用 |
|---|---|---|
| 地圖本體 | `AuntMap.cs` 的 `BuildAunt()`（約 620 行，全部用程式擺：房子、街道、糖果店、公園） | **要重寫一份**，但牆、門、窗、飾條、容器、家具這些小工具（SWall / SDoor / Window / SCont / SoftProps）都能直接用 |
| 地圖清單 | `Data.Themes`：已經有 阿姨家、便利商店、學校、阿嬤家、公園 五張卡，後四張 `playable=false`（施工中） | 選地圖畫面已經有，打開 `playable` 就能選 |
| 進地圖 | `LevelGen.BuildHouse()` 只認 `aunt`，其他走舊的通用生成 | 加一行 `if (th.id=="lib") return BuildLib(...)` |
| 寶貝 | `ThemeDef.items` 每張地圖自己的寶貝＋共用 `Data.Items` | 直接用，只要填表 |
| 貓狗 | `Pet.Create(dog/cat)`：巡邏、聽聲音、追、偷、被零食引開 | 直接用；新動物（鵝）＝ Pet 加一個種類，外觀要新做 |
| 公車撤離 | `Bus.Make(stop, laneDir)` | 直接用，只要給站牌位置 |
| 躲藏點 | `HideSpot.Setup(root)` 找名字叫 `sk_rtable`／`sk_curtain` 的物件 | 直接用；新躲點（書架、草堆、溜滑梯下）＝ 加名字＋種類 |
| 聲音圈 | `Stealth.cs` NoiseRing＋Player.NoiseR | 直接用；每張地圖的「特殊規則」只是在算 NoiseR 時乘一個數 |
| 家人願望、熊熊圖鑑、星星 | `Gameplay.cs`，從地圖寶貝表抽 | 直接用（圖鑑會自動多出新地圖的寶貝） |
| 自動測試 | `Game.cs` 寫死跑阿姨家（`ti = 0`），很多檢查認阿姨家的物件名字 | **要改**：測試要能指定地圖，每張地圖一份簡短檢查 |
| 擺放／比例檢查 | PlaceAudit、ScaleAudit、TrimDoorHits | 直接用，新物件要補比例規則 |

**結論**：系統面大概 80% 能重用。每張新地圖主要的新工作是「擺場景的程式」＋「新物件美術」＋「一條特殊規則」＋「測試」。真正難的是新角色：人（老師、管理員）目前完全沒有，貓狗以外的動物也要新做外觀。

## 二、四張地圖

（由 Claude 一起發想，我再依現有程式調整；超市因為跟阿姨家的房間走廊太像，先不做。）

### ① 圖書館「噓——」
- **主題**：閉館前的圖書館，夕陽從大窗灑進書架間。
- **配置**（約 36×26m，室內）：借還書臺（出生）、兒童繪本區、高書架迷宮、閱覽室、視聽小隔間、管理員辦公室、後門公車站（撤離）。
- **特色寶貝**：借書證章（普通）、絕版童話繪本（普通）、手繪書籤（稀有）、管理員老花眼鏡（稀有）、百年手抄本（傳說）。
- **威脅**：館貓 1 隻在書架間巡邏（耳朵比阿姨家的貓靈 1.5 倍）；管理員阿姨坐在櫃台**不走動**，只聽聲音，聽到就喊館貓過去。
- **特殊規則**：連續跑超過 3 秒，書會掉下來，多出一個 6m 聲音圈；可以丟「翻書聲」把館貓引走。躲點：書架縫、視聽隔間、桌子底下。
- **工作量**：小（約 4–6 天）。
- **風險**：耳朵太靈會讓小朋友挫折，要調；書架擋視線和躲藏要一致，不然「明明擋住還被看到」。
- 我的調整：Claude 原本讓管理員走動巡邏，但遊戲裡還沒有「人」的角色，所以改成坐著不動的管理員＋會走的館貓，省掉做走路的人。

### ② 外婆家農場「鵝叫警報」
- **主題**：稻田邊的三合院，雞舍、池塘、鵝群、看門狗。
- **配置**（約 60×40m，戶外）：曬穀場（出生）、三合院（外婆家）、雞舍、池塘＋鵝、稻田小徑、菜園／醃菜甕、大門牛車站（撤離）。
- **特色寶貝**：土雞蛋（普通）、醃梅子（普通）、外婆草帽（稀有）、外公老懷錶（稀有）、全家福相框（傳說）。
- **威脅**：看門狗 1 隻（跟旺財一樣）；鵝 3 隻，走很慢、耳朵普通，但很會看。
- **特殊規則**：鵝看到你會叫 3 秒，產生 8m 聲音圈，狗在圈內就會跑過來。先丟零食引開鵝，或從稻田繞。躲點：草堆、雞舍後面、三合院桌子底下。
- **工作量**：中（約 6–8 天）。三合院可以用阿姨家的房子工具改。
- **風險**：戶外比較空，躲點要夠；鵝叫加狗的連鎖不能太兇。

### ③ 幼兒園「午睡鐘聲」
- **主題**：放學後的幼兒園，蠟筆畫散在走廊，操場是蜂蜜色。
- **配置**（約 40×30m）：鞋櫃玄關（出生）、遊戲室、長走廊、教室＋午睡區、美術教室、保健室、操場／沙坑、校門公車站（撤離）。
- **特色寶貝**：彩色筆（普通）、貼紙卡（普通）、班級吉祥物（稀有）、老師星星印章（稀有）、畢業小獎盃（傳說）。
- **威脅**：值班老師在走廊來回；鐘響後多一位代班老師去操場。（可以先用「校狗」代替老師，省工）
- **特殊規則**：前 60 秒是午睡時間，聽力範圍減半、走得慢；鐘響後恢復正常，還會多一位巡邏的。鐘響前 10 秒要有明顯提示。
- **工作量**：中（約 7 天）；做「人」的話另加 4–5 天。
- **風險**：從安靜到戒備的轉換要提示清楚，不然像被偷襲。

### ④ 公園夜市「人聲掩護」
- **主題**：燈籠亮起的夜市＋公園，香味和人聲。
- **配置**（約 50×35m）：牌樓入口（出生）、小吃攤弄、套圈／彈珠攤、公園涼亭鞦韆、噴水池、收攤貨車區、公車站（撤離）。
- **特色寶貝**：糖葫蘆（普通）、彈珠汽水（普通）、手工風箏（稀有）、套圈大獎玩偶（稀有）、老闆的燈籠（傳說）。
- **威脅**：流浪狗 2 隻在攤位間、公園貓 1 隻。
- **特殊規則**：吵的地方你的聲音圈 ×0.6，噴水池再小一點；最後 90 秒攤販收攤，越來越安靜，要趁還吵的時候走。
- **工作量**：大（約 10–12 天）。人群就算只當背景也很多美術；燈光要從黃昏改成夜晚，跟現在的黃昏風格有落差。
- **風險**：人群要不要擋視線一開始就要定好；夜晚光線要另外調。

## 三、建議先做哪兩張

1. **圖書館**（先做）：最小、室內、只要一隻貓＋一個坐著的管理員，不用做會走路的人。它把「聲音圈」玩到最重，最容易看出新系統好不好玩。順便把「測試可以指定地圖」的基礎做好。
2. **外婆家農場**（第二）：重用房子工具和貓狗，新東西只有鵝（Pet 的新種類）和草堆躲點；戶外配阿姨家的街道經驗，黃昏稻田也最符合繪本水粉風。

幼兒園等「人」的角色做出來再做；夜市最大、要改夜晚光線，放最後。

每張開工前要先做的共通工作（約 1–2 天）：`BuildHouse` 依地圖分流、自動測試能指定地圖、`HideSpot` 支援新躲點種類、`Pet` 支援耳朵／眼睛倍率。
